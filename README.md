# 大连民生商品价格数据库

每日自动采集自大连市价格监测官方公开数据（jgjc.pc.dl.gov.cn），覆盖三类市场，供 WorkBuddy 用户通过 `dalian-price` Skill 免费查询问答。

## 数据来源与口径

- 来源：大连市价格监测官网公开发布的价格表（每日约 10:00–12:00 更新，节假日休市无数据）
- 采集方式：每日定时抓取官网列表页 → 下载价格表图片 → 人工级校对转录 → 入库 SQLite
- 数据自 **2026-01-04** 起（首版范围，2026 年全年）

## 三张价格表（结构一致，物理隔离）

| 表 | 市场 | 计量单位 |
|---|---|---|
| `price_farm` | 农贸市场 | 元/500g（桶装油 元/5L） |
| `price_supermarket` | 生鲜超市 | 元/500g（桶装油 元/5L） |
| `price_wholesale` | 批发市场 | **元/公斤**（比价时注意换算） |

字段：`report_date`（YYYY-MM-DD）、`seq`、`category`、`commodity`、`spec`、`unit`、`avg_price`（平均价）、`prev_price`（上期价）、`mom_pct`（日环比 %）。主键 `(report_date, seq)`。

注意：三套市场的商品目录**不完全相同**（批发市场仅 21 种蔬菜；生鲜超市无乳制品等），跨市场对比以各自实际商品为准。

## 数据获取（按天增量 + 全量快照混合）

- **每日增量**：`data/<market>/<date>.json`，每个数据日期一个紧凑 JSON 文件（三市场各一份，单文件约 2–4 KB）。日常更新只拉缺失日期的文件即可，KB 级流量。
- **全量快照**：[Releases · Latest](../../releases/latest) 中的 `dalian_market_price_<日期>.db`（SQLite，约 3 MB），供首次安装一次性下载。
- **版本元信息**：`version.json` —— `latest`（各市场最新日期）、`rows`（各表行数）、`dates`（完整日期清单）、`snapshot`（快照文件名）。

`dalian-price` Skill 的 `sync_db.py` 自动选择路径：无缓存或缺口大 → 下载快照；日常 → 逐日拉增量文件合并入库。通常无需手动操作。
